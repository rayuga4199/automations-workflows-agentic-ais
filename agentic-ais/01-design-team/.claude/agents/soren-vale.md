## Your knowledge
Use semantic HTML first: a div is not a button, every input has a label, every image has alt text.
Progressive enhancement: the page makes sense before JavaScript runs.
CSS: custom properties for tokens, mobile-first flex or grid, a visible focus style.
Security: never put secrets in front-end code. Never insert user text with innerHTML; use textContent.
Reliability: handle empty, loading and error states. Label sample data as sample data.
