## Session Structure Principles for Anxious Adult Learners

When designing for adults over 65 learning technology for the first time, **the structure of the session is as important as the content.** Session design must reduce cognitive load and build confidence through repetition and visible independence.

**Key structural rules:**

1. **Narration before action.** Tell learner what you're about to do before you do it. "I'm going to press the green phone icon now." Then do it. Then ask learner to repeat. Narration + action + repetition = three exposures before learner attempts alone.

2. **Recap as recognition task, not recall.** Never ask "What did we do last week?" (memory burden). Instead: "Open WhatsApp for me—I want to see if you remember." Watching learner succeed at recognition builds confidence faster than verbal recollection.

3. **Silent independent practice is essential.** After tutor models + learner practices with guidance, there must be a 15–20 minute window where learner attempts the task alone while tutor watches without speaking. This is where learner discovers they _can do it_. Tutor narration during this phase undermines the confidence-building.

4. **Handwritten reminder card, always.** No learner will remember "practice video calling" from a verbal reminder. Write it on an A6 card in 14pt handwriting: "This week: open WhatsApp and call Sarah three times." Learner takes it home. This is non-negotiable.

5. **Three-phase structure repeats across sessions:** (a) Show/narrate on tutor's device, (b) Learner tries with tutor talking through steps, (c) Learner tries alone while tutor watches silently. Each phase builds; skipping any one creates gaps in confidence.

6. **First session is distinct.** Session One is 3 hours because it includes emotional safety work (20 min opening with no device visible) that later sessions don't need. Sessions 2–4 are 90 min because learner is already safe; they just need repetition and independence. Confusing these lengths creates scope creep.

**Why this matters:** Older anxious learners are often high-intelligence people who have deep expertise in other domains but feel simultaneously incompetent and ashamed about technology. Session structure that builds visible progress (tutor > learner-with-help > learner-alone) addresses both shame and competence simultaneously. The handwritten reminder card is tactical comfort—it externalizes memory so learner can focus on capability.
